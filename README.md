# 海のちずパズル v2

小5・中学受験の地理学習向けに、日本の山地・山脈と川の**名前・場所・形・重要知識**を段階的に覚えるWebアプリです。

## v2で直したこと

- 47都道府県を含む完全な日本地図SVGを直接表示
- 山地・山脈・高地は21項目すべてに固有の簡略形状を設定
- 川は22項目すべてに固有の簡略流路を設定
- 正解位置を全モードで見せる方式を廃止
- 項目ごとの習熟度に応じてヒントを5段階で自動調整
- 間違えたときはヒントを1段戻して再挑戦
- 「よみとく」モードを追加し、特徴・歴史・典型的な問われ方から地形名を選んでから地図に配置

## 5段階学習

1. 正しい形を表示して重ねる
2. 正しい形をうっすら表示
3. 正解のある地域だけを広く示す
4. 地図上の正解位置は一切表示せず、文字ヒントのみ
5. 県境だけの完全テスト

正解が続くと習熟度が上がり、ヒントが減ります。間違えると習熟度を1段戻して復習します。

## 主な機能

- 山地・山脈・高地：21項目
- 川：22項目（教材地図＋重要表にある球磨川を含む）
- おぼえる
- ちょうせん
- マスターテスト
- よみとく
- にがて復習
- 重要特徴・関連知識・歴史情報・典型問題の表示
- Web Speech APIによる日本語読み上げ
- Web Audio APIによるタップ、近接、吸着、正解、不正解、クリア音
- localStorageによる習熟度・苦手記録保存
- iPhone / iPad対応
- PWA / オフラインキャッシュ

## 地形表現について

山地・河川の線はGISの精密データをそのまま描くのではなく、**小5の教材白地図で位置・向き・長さを覚えやすいよう単純化した固有形状**です。各項目で同じ形を使い回していません。

## 知識データの基準

初版教材としてユーザー提供の白地図ページを正本にし、河川の日本順位や主要な歴史事項は国土交通省等の公的資料と照合しています。例：

- 信濃川：長さ367kmで日本最長、流域面積は日本第3位
- 利根川：長さ322kmで日本第2位、流域面積は日本最大
- 木曽川・長良川・揖斐川：木曽三川
- 利根川東遷：江戸時代初期の流路付替え

## 拡張設計

同じ地図学習エンジンに、今後以下を追加できる構成です。

- 平野・盆地・台地
- 半島・岬・湾・海峡
- 気候
- 干拓地・用水
- 漁港
- 工業・伝統工業
- 新幹線
- 森林

テーマ表示は分離してあり、海の生き物版とは別にスーパーカーテーマへ展開できます。
