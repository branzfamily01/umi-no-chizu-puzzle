# 海のちずパズル

小5・中学受験の地理学習向けに、日本の山地・山脈と川の位置を県境つき日本地図へ「はめる」パズルで覚えるWebアプリです。

## 初版の主な機能

- 山地・山脈：21項目
- 川：21項目
- 学習モード
- 形パズル
- 名前札パズル
- テストモード（やさしい / ふつう / むずかしい）
- 苦手問題の自動記録・復習
- Web Speech APIによる日本語読み上げ
- Web Audio APIによるタップ音、近接音、吸着音、正解音、不正解音、クリア音
- localStorageによる学習記録保存
- iPhone / iPadレスポンシブ対応
- PWA / オフラインキャッシュ

## GitHub Pagesで公開する方法

このフォルダの**中身をそのまま**GitHubリポジトリのルートへアップロードしてください。ZIPファイルそのものをアップロードするのではなく、ZIPを解凍した中身（`index.html`、`styles.css`、`app.js`、`data/`、`assets/`、`manifest.json`、`sw.js` など）をアップロードします。

GitHub Pagesでは公開ブランチを `main`、公開元をリポジトリルートに設定します。

## 拡張設計

学習データとテーマ表示を分離しているため、今後次のカテゴリを追加できます。

- 平野・盆地・台地
- 半島・岬・湾・海峡
- 気候
- 干拓地・用水
- 漁港
- 工業・伝統工業
- 新幹線
- 森林

また、同じ地理パズル基盤を使い、海の生き物テーマとは別にスーパーカーテーマへ展開できる構造を想定しています。

## 補足

地図上の山地・河川パーツは小学生の位置記憶用に視認性を優先した学習表現であり、測量用の厳密な地形データではありません。
